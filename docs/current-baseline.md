# ことばの保管庫：現在の基準版

この文書は、別チャットで試したベータ機能を含め、現在の `origin/main` にある状態を今後の開発基準として固定するためのメモです。

## 中核機能

- 思いついた文章を原文のまま保存する
- 保存直後に関連する過去の記録を近い順で最大10件表示する
- 関連記憶へ「近い／違う」の評価を付ける
- 自然文検索、最近の言葉、編集履歴、ゴミ箱を使う
- オフライン時は端末に預かり、通信復旧後に同期する
- スマホで保存した記録を Codex / ChatGPT 側の `recall_related` から検索する

## 「あとでやる」

「あとでやる」は厳密なタスク管理ではなく、行動につながりそうな言葉へ印を付ける機能です。

- 「書く｜あとでやる｜探す｜最近」の下部メニュー
- 登録、もう少しあとで、やってやった、中止、再登録
- 「これまで」に完了・中止した項目を表示
- 期限、優先度、チェックリスト、複雑なステータス管理は作らない

## ベータ機能

- 過去の記録へ「今の自分から返す」対話
- 保存後に設定する「あとで考える」リマインダー
- 「あとでやる」の最初の一歩、開くURL、ルーレット

対話とリマインダーは、実際の使い勝手を確認するまでベータ扱いにします。設定で無効化できる状態を維持します。

## PCローカル版の補助

PCのローカル版では、「あとでやる」に作業フォルダを紐づけ、フォルダの選択・作成・ファイル追加・起動を行えます。これはローカル環境向けの補助であり、スマホのクラウド版とは分けて扱います。

## 除外するもの

- 音声入力
- 自動的なタスク化
- 期限・優先度・チェックリスト
- 毎日のレビューを要求する仕組み
- 原文の自動要約・自動言い換え

## 開発運用

- このチャットを開発本線とする
- 別チャットの変更は、ブランチ名・コミット番号・変更内容を確認してから統合する
- 実装前に `origin/main` と同期する
- 変更後は保存、関連記憶最大10件、あとでやる、検索、最近、オフライン保存を回帰確認する

## 基準版の確認

```powershell
pnpm test
pnpm typecheck
pnpm build
```

音声関連の `SpeechRecognition`、`voice=1`、PWAショートカットは基準版に存在しません。
